# M3 文件传输 — 子任务清单

> 来源：《[飞联-开发任务拆解.md](../飞联-开发任务拆解.md)》M3 节 · 状态图例：✅ 完成 ｜ 🔶 进行中 ｜ ⬜ 未开始
>
> **目标**：飞联之间可靠传输文件与整个文件夹，UI 传输卡片真实刷新。
> **前置**：M2 完成（可与 M4 并行）。
> **注意**：与飞秋互通时文件传输为尽力而为项（需求文档 §4.2），优先保证飞联 ↔ 飞联全功能。

## T-M3-1 文件消息协议 ⬜ <a id="T-M3-1"></a>

- [ ] `CmdSendMsg|OptFileAttach`，Extra 为文件列表
- [ ] 对齐 IPMsg 0x0011 扩展格式：`fileID:名字:大小:属性`（多文件以 `\0` 分隔）
- [ ] 飞联扩展字段：目录树（folder 标记）
- [ ] 单元测试覆盖编解码

**验收**：与飞鸽官方格式字段对齐，单测通过。
**依赖**：M1。**落点**：`engine/protocol.go`。

## T-M3-2 TCP 传输通道 ⬜ <a id="T-M3-2"></a>

- [ ] 监听 TCP 2425
- [ ] 对方接受后按块拉取（默认 64KB/块）
- [ ] 飞联之间协商并发多块传输
- [ ] 传输限速机制

**验收**：1GB 文件传输成功；限速可生效。
**依赖**：T-M3-1。**落点**：`engine/transfer/`（新建子包）。

## T-M3-3 传输管理器 ⬜ <a id="T-M3-3"></a>

- [ ] 任务表：进度 / 速度 / 取消 / 完成事件（`EventFileRequest` / `EventFileProgress` / `EventFileDone` 已在 engine.go 定义）
- [ ] 重复文件名落盘策略（重命名/覆盖）

**验收**：UI 传输卡片两种状态（进行中/已完成）真实刷新。
**依赖**：T-M3-2。

## T-M3-4 文件夹递归 ⬜ <a id="T-M3-4"></a>

- [ ] 发送侧递归展开目录树
- [ ] 接收侧按树重建目录结构

**验收**：传多层嵌套文件夹结构完整。
**依赖**：T-M3-2。

## T-M3-5 UI 与设置落地 ⬜ <a id="T-M3-5"></a>

- [ ] 聊天头部「发文件 / 发文件夹」接真实选盘（Wails runtime dialog）
- [ ] 「接收目录 / 传输完成后自动打开」设置生效

**验收**：全流程可点通。
**依赖**：T-M3-3。**落点**：`frontend/src/components/ChatPanel.tsx`、`app.go` 增加 dialog 绑定。

## T-M3-6 （可选）断点续传 ⬜ <a id="T-M3-6"></a>

- 待定问题 §8-4，**默认不做**；若做则在此补充清单。

飞联之间传 1GB 文件夹成功且可续看进度（对应需求文档 §7 M3 验收标准）。
