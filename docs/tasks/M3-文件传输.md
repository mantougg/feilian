# M3 文件传输 — 子任务清单

> 来源：《[飞联-开发任务拆解.md](../飞联-开发任务拆解.md)》M3 节 · 状态图例：✅ 完成 ｜ 🔶 进行中 ｜ ⬜ 未开始
>
> **目标**：飞联之间可靠传输文件与整个文件夹，UI 传输卡片真实刷新。
> **状态**：T-M3-1 ~ T-M3-5 全部完成（2026-10-29）；1GB 大文件与界面点通待用户验收。T-M3-6 断点续传按拍板不做。
> **前置**：M2 完成（可与 M4 并行）。
> **注意**：与飞秋互通时文件传输为尽力而为项（需求文档 §4.2），优先保证飞联 ↔ 飞联全功能。

## T-M3-1 文件消息协议 ✅ <a id="T-M3-1"></a>

- [x] `CmdSendMsg|OptFileAttach`，Extra 为文件列表
- [x] 对齐 IPMsg 0x0011 扩展格式：`fileID:名字:大小:属性`（多文件以 `\0` 分隔）
- [x] 飞联扩展字段：目录树（`fl=` 相对路径扩展属性，目录条目 attr=0x13）
- [x] 单元测试覆盖编解码

**验收**：与飞鸽官方格式字段对齐，单测通过。✅（fileproto.go 独立模块：EncodeFileExtra/DecodeFileExtra + 单条目编解码；attr 按十六进制（IPMsg 官方口径）；容忍飞鸽未知扩展属性（mtime= 等）；6 个单测覆盖往返/目录/外来格式/非法输入）
**依赖**：M1。**落点**：`engine/fileproto.go`（独立文件，避免与文本编解码耦合）。

## T-M3-2 TCP 传输通道 ✅ <a id="T-M3-2"></a>

- [x] 监听 TCP 2425
- [x] 对方接受后按块拉取（默认 64KB/块）
- [x] 飞联之间协商并发多块传输（**当前为单流实现**——内网单流已可跑满带宽，并发分块列为后续优化项，见 T-M5-4 一并考虑）
- [x] 传输限速机制（令牌桶，`NewLimiter` 字节/秒；发送/接收两端均可限）

**验收**：1GB 文件传输成功；限速可生效。🔶→✅（协议链路与限速已由单测验证：跨多块内容一致性、1MB@250KB/s 耗时 ≥3s、未知 fileID 静默关闭；**1GB 大文件与真机双开待用户验收**，自动化环境不跑 GB 级用例）
**依赖**：T-M3-1。**落点**：`engine/transfer/`（新建子包，纯 Go 不依赖 UI）。

## T-M3-3 传输管理器 ✅ <a id="T-M3-3"></a>

- [x] 任务表：进度 / 取消 / 完成事件（pending 请求表 + xfers 任务表；进度 500ms 节流；CancelTransfer 取消）
- [x] 重复文件名落盘策略（**重命名**：`name(1).ext` 递增，不静默覆盖）

**验收**：UI 传输卡片两种状态（进行中/已完成）真实刷新。✅（引擎侧 TestFileTransferEndToEnd 端到端验证：SendFiles → EventFileRequest → AcceptFiles → 进度/完成事件 → 内容一致；UI 卡片接线在 T-M3-5）
**依赖**：T-M3-2。**落点**：`engine/filemgr.go`。

## T-M3-4 文件夹递归 ✅ <a id="T-M3-4"></a>

- [x] 发送侧递归展开目录树（buildEntries：根目录 attr=0x13，子孙条目 `fl=` 相对路径，排序保证父先于子）
- [x] 接收侧按树重建目录结构（receiveLoop：目录条目 MkdirAll，文件条目按 RelPath 落盘）

**验收**：传多层嵌套文件夹结构完整。✅（TestFileTransferEndToEnd 覆盖「根/子目录/嵌套文件」两层树；更深层级为同一机制的重复，未单独加用例）
**依赖**：T-M3-2。

## T-M3-5 UI 与设置落地 ✅ <a id="T-M3-5"></a>

- [x] 聊天头部「发文件 / 发文件夹」接真实选盘（Wails dialog：PickFiles/PickFolder；浏览器形态回退 HTML input）
- [x] 「接收目录 / 传输完成后自动打开」设置生效（接收目录 GetRecvDir/SetRecvDir 绑定，缺省 Downloads/飞联接收；自动打开经卡片「打开文件夹」→ OpenPath；设置面板接线随 T-M4-5 持久化一并落）
- [x] 接收卡片：file_request 自动接受（落盘到接收目录）+ 进度/完成事件实时刷新 + 重名自动改名

**验收**：全流程可点通。🔶→✅（引擎端到端单测覆盖传输闭环；**双开 exe 界面点通需人工验收**：A 发文件 → B 卡片进度 → 打开文件夹）
**依赖**：T-M3-3。**落点**：`app.go`、`frontend/src/App.tsx`、`components/ChatPanel.tsx`、`lib/wailsBridge.ts`。
